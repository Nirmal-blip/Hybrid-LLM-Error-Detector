# Hybrid LLM Error Detector - Frontend

Vite + React 18 + Tailwind CSS frontend interface with Monaco Editor and dark developer dashboard.

## Features
- **Monaco Code Editor**: Full C++ syntax highlighting, line numbers, and minimap.
- **Custom Test Suite Management**: Manage inputs and expected outputs dynamically.
- **Preset Benchmark Selector**: 1-click loading of classic algorithmic logical bugs.
- **Live Pipeline Progress**: 6-step progress monitor with animated feedback.
- **Structured Results Dashboard**: Overview, Bug Findings, Test Cases, Code Comparison (Diff), Suggested Fix, and Execution Logs.
- **Analysis History & Metrics**: Real persistence with view and reload capabilities.
- **System Diagnostics**: Real-time health monitor for backend, compiler, and Groq status.

## Running

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build
```
Default URL: `http://localhost:5173`
